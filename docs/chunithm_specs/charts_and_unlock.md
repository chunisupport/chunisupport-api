# 楽曲・譜面と解禁

楽曲のカテゴリ、譜面の難易度、解禁条件、マップ、WORLD'S END、クラス認定（コースモード）についてまとめます。
用語の短い定義は [README.md の用語集](README.md#用語集) を参照してください。

> 記載内容は2026年10月時点（CHUNITHM Mate稼働中）の情報です。

---

## 楽曲カテゴリ（ジャンル）

楽曲は次のカテゴリに分かれます。カテゴリはバージョンアップのときに移動することがあります（Mateでも一部の楽曲が移動しました）。

| カテゴリ | 内容 |
|---|---|
| POPS & ANIME | J-POP、アニメソングなど |
| niconico | VOCALOID曲など |
| 東方Project | 東方アレンジ |
| VARIETY | BMS、インディーズ、他社ゲーム音楽など |
| イロドリミドリ | CHUNITHMオリジナルのうち、メディアミックス「イロドリミドリ」の楽曲 |
| ゲキマイ | maimai・オンゲキのオリジナル楽曲 |
| ORIGINAL | 上記以外のCHUNITHMオリジナル楽曲 |

- 新しい楽曲は、だいたい2週間ごとの木曜日に追加されます（イベントマップの開放と同時のことが多い）。
- 楽曲は削除されることもあります。削除された楽曲はゲームで遊べなくなり、CHUNITHM-NETにも出なくなります。このプロジェクトでは、削除された楽曲をOVER POWERの計算から除きます。

## 難易度と解禁

| 難易度 | 略称 | 色 | 持っている楽曲 | 遊べる条件 |
|---|---|---|---|---|
| BASIC | BAS | 緑 | すべての通常楽曲 | 楽曲が解禁されていれば遊べる |
| ADVANCED | ADV | 橙 | すべての通常楽曲 | 同上 |
| EXPERT | EXP | 赤 | すべての通常楽曲 | 同上 |
| MASTER | MAS | 紫 | すべての通常楽曲 | その楽曲のEXPERT以上でランクSを取る、またはチケットを使う |
| ULTIMA | ULT | 黒 | 一部の楽曲だけ | その楽曲のEXPERT以上でランクSを取る、またはチケットを使う |
| WORLD'S END | WE | — | WORLD'S END楽曲だけ | 全難易度プレイチケットなどを使う |

- 解禁していない難易度でも、全難易度プレイチケット（ゲーム内通貨500）やプレミアムチケットを使えば、そのクレジットの間だけ遊べます。
- ULTIMAの解禁条件は、LUMINOUSまでは「EXPERTとMASTERの両方でランクSS以上」でした。
- ULTIMAはNEWで追加された難易度です。楽曲が出たあとでULTIMA譜面だけ追加されることもあります。
- 2025年12月に、初めてレベル16の譜面（Linked VERSEの最終課題曲「Melodiniq」のULTIMA）が登場しました。
- 楽曲そのものが解禁されていない（マップの報酬や課題曲を取っていない）こともあります。このプロジェクトでは、プレイヤーが未解禁の楽曲や譜面を設定できます（[player_locked_songs.md](../player_locked_songs.md)）。

## レベルと譜面定数

- 通常譜面にはレベル（1〜16、7以上には「+」付きの中間レベルもある）があります。レーティングとOVER POWERには、それより細かい**譜面定数**（0.1刻み）を使います。
- 譜面定数は公式には公開されていません。有志がプレイ結果から逆算して求めます。新しい譜面は、定数がわかるまで暫定値で扱います。
- レベルと譜面定数の対応は [README.md の用語集](README.md#楽曲譜面関連) を参照してください。

## WORLD'S END

- PLUSで追加された特殊な難易度です。テーマに沿って極端な仕掛けがある譜面が入っています（逆再生、停止、ノーツごとに違う速度、すべてHOLD判定、など）。
- レベルの代わりに、テーマを表す1文字（「改」「止」「光」「割」「狂」など）と、難しさを表す★1〜5で表します。
- 遊ぶには全難易度プレイチケット（ゲーム内通貨500）などが必要です。昔はWORLD'S END専用のチケットがありましたが、Mateで廃止されました。
- **レーティング、OVER POWER、トータルハイスコアには関係しません。**
- WORLD'S END専用の楽曲（通常譜面を持たない）があります。同じ曲名の通常楽曲とは別の楽曲として扱います。
- コースモードでしか遊べないWORLD'S END譜面もあります。
- DAMAGEノーツ（触れるとMISS）は、原則としてWORLD'S ENDにしか出てきません。

## マップと課題曲

- プレイするたびに、成績に応じてすごろくのようなマップを進みます。マスの報酬で楽曲、キャラクター、称号、ネームプレートなどが手に入ります。
- X-VERSEから、BASIC・ADVANCEDでもEXPERTと同じだけ、WORLD'S ENDでもMASTER・ULTIMAと同じだけマップを進めるようになりました。
- 一部のマップはゴールに課題曲があり、クリアしないと次のマップへ進めません。課題曲をクリアすると、その楽曲が解禁されます。
- 課題曲のクリアノルマはマップごとに決まっています。必要なゲージの本数は、選んだ難易度によって違います。
- 大型アップデートのたびに、前々バージョンのマップは削除されます（そこでしか取れなかった楽曲は、別の方法で解禁できるようになることが多い）。
- マップ以外の解禁手段として、UNLOCK CHALLENGE、Linked VERSE（X-VERSEから）などのイベントがあります。

## クラス認定（コースモード）

- AIR PLUSで「コースモード」として追加され、NEWで「クラス認定」に名前が変わりました。
- 決められた3曲を続けて遊びます。いちばん低い難易度の曲でもLEVEL9以上の、上級者向けのモードです。
- コースごとにライフがあり、ATTACK以下やJUSTICE以下でライフが減ります。0になると曲の途中でも終了します。ライフの数や、曲ごとに回復するかどうかはコースによって違います。
- クリアすると、そのクラスのエンブレムがネームプレートに付き、アイテムがもらえます。
- NEW PLUSから、特定のコースをクリアするまで遊べないコースが追加されました。
- 月替わりのチームコースもあります。X-VERSE-XからULTIMAも選べるようになりました。

## CHUNITHM-NET

- 公式のプレイヤー向けサイトです。SEGA IDにAimeカードを連携して使います。NEWから「CHUNITHM-NET!!」として作り直されました（PARADISE LOSTまでのデータとは別）。
- ランキング、マップの進み具合、プロフィールなどが見られます。一部の機能（フレンドのスコア表示など）は月額のスタンダードコースに入る必要があります。チーム機能はスタンダードコースに入っていなくても使えます。
- **このプロジェクトでは、CHUNITHM-NETでブックマークレットを動かしてスコアデータを集めます。**
- アイテム交換所で、ゲーム内通貨やPポイント（1クレジットにつき1pt、1日30ptまで）とアイテムを交換できます。
