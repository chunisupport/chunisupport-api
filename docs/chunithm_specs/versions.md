# バージョン一覧

国内版CHUNITHMの歴代バージョンと稼働開始日をまとめます。新曲枠や「現バージョンで追加された楽曲」がどれかを判定するときの参考にしてください。
「大型アップデート」と「バージョン」の定義は [README.md の用語集](README.md#ゲーム関連) を参照してください。

> 記載内容は2026年10月時点の情報です。

---

## 国内版

- 名前の変わり方は基本的に「〇〇 → 〇〇 PLUS → 次のタイトル」ですが、PARADISE → PARADISE LOST や VERSE → X-VERSE → X-VERSE-X のような例外もあります。

## 海外版

- 国内版とは別に、国際版（SUPER STAR、NEW!!、SUN、VERSEなど）と中国版（CHUNITHM 2024など）があります。収録曲や稼働時期が国内版と違います。
- このディレクトリのドキュメントは国内版を前提に書いています。
