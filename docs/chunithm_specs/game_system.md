# ゲームシステム

CHUNITHMの1プレイの流れ、操作、ノーツ、判定、スコア、ランク、ランプ、スキルについてまとめます。
レーティングやOVER POWERの計算式は [rating_calculation.md](../rating_calculation.md) と [overpower_calculation.md](../overpower_calculation.md) を参照してください。

> 記載内容は2026年10月時点（CHUNITHM Mate稼働中）の情報です。スキルの数値やチケットの価格は、大型アップデートのたびに変わることがあります。

---

## 筐体と操作

- 画面の手前にあるタッチパネル「グラウンドスライダー」で、奥から流れてくるノーツをタッチします。スライダーは16分割のレーンとして扱われます。
- 筐体の左右にある空間センサー「エアーストリングス」が、スライダーの上で手を上げ下げする動きを検知します（AIR系ノーツ）。
- Aime・バナパスポート・Amusement IC対応カードなどでプレイデータを保存します。カードを使わなくてもプレイできますが、記録は残りません。
- 店内マッチングで最大4人まで同時にプレイできます。

## 1クレジットの流れ

1. コインを入れてカードをタッチし、プレイヤーデータを読み込む。
2. マップを選ぶ（後述の [マップ](charts_and_unlock.md#マップと課題曲)）。
3. チケットを選ぶ。クレジットを追加するとプレミアムチケット（マップの進みを早めるもの、全難易度を遊べるものなど）を買える。
4. 楽曲と難易度を選ぶ。確認画面で、キャラクター、スキル、ノーツ速度などを変えられる。
5. 曲をプレイする。1クレジットで遊べる曲数は、基本は3曲（店舗の設定やチケットによって変わる）。
6. リザルトのあと経験値とアイテムが加算され、USER BOXで称号、ネームプレート、マップアイコン、システムボイスなどを変えられる。

## ノーツの種類

| ノーツ | 色・形 | 操作 | 備考 |
|---|---|---|---|
| TAP | 赤 | タイミングよくタッチする | |
| ExTAP | 黄 | TAPと同じ | 大きくずれない限りJUSTICE CRITICALになる |
| HOLD | 黄色の帯 | 終点までタッチし続ける | 終点を過ぎてから離しても判定は変わらない |
| SLIDE | 青い帯 | タッチしたまま、形に合わせて左右に動かす | 途中で幅が変わるものもある |
| FLICK | 水色 | タイミングに合わせて左右にこする | |
| DAMAGE | — | 触れてはいけない | 触れるとMISS。主にWORLD'S END専用（例外的に通常譜面に出たこともある） |
| AIR | 緑の矢印 | 手を上げる（紫の下向きは手を下げる） | 多くはTAP・HOLD・SLIDEの終端に付く |
| AIR-HOLD | 緑の帯 | 手を上げたままにする | 途中の紫のAIR-ACTIONでは手を上下に振る |
| AIR-SLIDE | 緑の帯（左右に動く） | 手を上げたままにする | NEWで追加。センサーの仕組み上、左右に動かさなくても判定される |
| AIR-CRUSH | 硬い見た目のAIR-ACTION | 手を上下に振る | NEWで追加 |

- AIR-HOLDに似た紫の線（通称「レインボーン」）は演出用で、判定もノーツ数のカウントもありません。
- 「総ノーツ数」は、判定があるノーツの合計です。HOLDやSLIDEは長さに応じて複数の判定を持ちます。

## 判定

ノーツごとに、次の4段階で判定されます。

| 判定 | 1ノーツあたりの配点（JUSTICEを100%とする） | コンボ |
|---|---|---|
| JUSTICE CRITICAL | 101% | つながる |
| JUSTICE | 100% | つながる |
| ATTACK | 50% | つながる |
| MISS | 0% | 切れる |

- JUSTICE CRITICALより内側に「JUSTICE HEAVEN」があるともいわれますが、スコアには関係しません。
- Mateから、リザルトにFAST/LATE（早すぎ・遅すぎ）の数が表示されるようになりました。

## スコア

- 全ノーツをJUSTICEで取ると1,000,000点、全ノーツをJUSTICE CRITICALで取ると **1,010,000点（理論値）** です。
- 1ノーツあたりの基本点は「1,000,000 ÷ 総ノーツ数」で、そこに上の表の配点率を掛けます。そのため、同じ判定数でも総ノーツ数が少ない譜面ほど、1つのずれで失う点が大きくなります。
- スコアから、楽曲ランク、レーティング、OVER POWERが決まります。
- スキルのボーナス（後述）は**スコアには影響しません**。ゲージにだけ影響します。
- 1つの譜面について、自己ベストのスコアだけが記録されます。

## 楽曲ランク

楽曲ランクは14段階で、スコアの下限で決まります。S+・SS+・SSS+はNEWで追加されました。

| ランク | スコア下限 |
|---|---|
| SSS+ | 1,009,000 |
| SSS | 1,007,500 |
| SS+ | 1,005,000 |
| SS | 1,000,000 |
| S+ | 990,000 |
| S | 975,000 |
| AAA | 950,000 |
| AA | 925,000 |
| A | 900,000 |
| BBB | 800,000 |
| BB | 700,000 |
| B | 600,000 |
| C | 500,000 |
| D | 0 |

- 単曲レーティングはSSS+（1,009,000点）で頭打ちになります。OVER POWERは理論値まで伸びます。
- MASTERとULTIMAを解禁する条件にもランクSが使われます（[難易度と解禁](charts_and_unlock.md#難易度と解禁)）。

## ランプ（特殊評価・クリアマーク）

「ランプ」は公式の用語ではありません。BEMANIシリーズでの呼び方を借りています。このプロジェクトでは、コンボランプとクリアランプを分けて扱います。

### コンボランプ（特殊評価）

| ランプ | 条件 | 表示 |
|---|---|---|
| FULL COMBO (FC) | 全ノーツATTACK以上（MISSなし） | リザルトと楽曲選択画面 |
| ALL JUSTICE (AJ) | 全ノーツJUSTICE以上 | リザルトと楽曲選択画面 |
| ALL JUSTICE CRITICAL (AJC) | 全ノーツJUSTICE CRITICAL（＝理論値） | リザルトに「AJC」と出る。CHUNITHM-NETのランキングにAJC回数が出る |

- AJC ⊂ AJ ⊂ FC の包含関係です。AJCは「スコアが1,010,000点」と同じ意味です。
- このプロジェクトでは、AJCを「スコアが1,010,000点かどうか」で判定します（[overpower_calculation.md](../overpower_calculation.md) を参照）。

### フルチェイン

- 店内マッチングで、プレイヤー全員がFULL COMBO以上を取ると「FULL CHAIN」になります。
- 自分より低い難易度の人がいると金、全員が同じかそれより高い難易度ならプラチナのFULL CHAINになります。

### クリアランプ（クリアマーク）

- 曲が終わった時点でゲージのノルマを満たしていればCLEARです。プレイしたがCLEARしていない譜面は、このプロジェクトではFAILEDとして扱います。
- 強制終了がある特定のスキルを使い、強制終了しないで曲を終えると、より上位のクリアマークが付きます（NEWから）。
- 強制終了せずに曲を終えれば、ほとんどの場合CLEARは付きます。このため、CLEARだけでは上手いとは言いづらいです。

| クリアランプ | 強制終了の条件 | 対応スキル（VERSE以降の分類） |
|---|---|---|
| CLEAR | なし | スキルなし・NORMAL・OTHERのスキル |
| HARD | MISS 20回 / MISS 10回 / JUSTICE以下 300回 | ジャッジメント / オーバージャッジ / 嘆きのしるし |
| BRAVE | JUSTICE以下 150回 | 勇気のしるし |
| ABSOLUTE | JUSTICE以下 50回 | 道化師の狂気 |
| CATASTROPHY | JUSTICE以下 10回 | 天地創造 |

- 上位のクリアランプは、下位のクリアランプも満たしているものとして扱います（CATASTROPHY ⊃ ABSOLUTE ⊃ BRAVE ⊃ HARD ⊃ CLEAR）。
- スキルとクリアマークの対応や名前はバージョンによって違います（例: NEW〜LUMINOUS PLUSには「ABSOLUTE+」があり、嘆きのしるしはABSOLUTEでした）。
- コンボランプとクリアランプは独立しています。例えば「HARDでFCしていない」状態や「CLEARだけでAJ」状態もあり得ます。

## スキルとゲージ

- プレイ画面の上にゲージがあり、ノーツを取ると増えます。曲が終わった時点で一定の本数に届いていればCLEARです。
- スキルはゲージの増え方を変えたり、強制終了の条件を付けたりします。**スコアは変わりません。**
- 「スキルシード」を使ってスキルを入手・強化します（GRADE）。GRADEが上がると効果が強くなります。新しいバージョンが始まると、古いスキルが整理されたり統合されたりします。

### VERSEのスキル一覧（GRADE1）

| 分類 | スキル | 効果 |
|---|---|---|
| — | スキルなし | — |
| NORMAL | ゲージブースト | ゲージ上昇 175% |
| NORMAL | コンボエクステンド | 100コンボごとにボーナス +3,500 |
| HARD | ジャッジメント | ゲージ上昇 210%、MISS 20回で強制終了 |
| HARD | オーバージャッジ | ゲージ上昇 230%、MISS 10回で強制終了 |
| HARD | 嘆きのしるし | JUSTICE CRITICALでボーナス +22.50、JUSTICE以下 300回で強制終了 |
| BRAVE | 勇気のしるし | JUSTICE CRITICALでボーナス +32.50、JUSTICE以下 150回で強制終了 |
| ABSOLUTE | 道化師の狂気 | JUSTICE CRITICALでボーナス +53.00、JUSTICE以下 50回で強制終了 |
| CATASTROPHY | 天地創造 | ゲージ上昇 400%、JUSTICE以下 10回で強制終了 |
| OTHER | 限界突破の証 | ゲージ上昇 100%、1,010,000点で終了時ボーナス +30,000 |
| OTHER | 真・限界突破の証 | ゲージ上昇 150%、1,010,000点で終了時ボーナス +50,000、MISS 10回で強制終了 |
| OTHER | 絆・限界突破の証 | ゲージ上昇 200%、JUSTICE以下で追加ダメージ −3,000、1,010,000点で終了時ボーナス +70,000 |
| OTHER | キャンペーンブースト | 終了時にランクに応じたボーナス（S +36,000 / SS +54,000 / SSS +72,000） |

「ボーナス」と「ダメージ」はゲージの量です。スコアではありません。

## キャラクター

- プレイのたびに、設定したキャラクターに経験値が入り、RANKが上がります。初めはRANK1、上限は15です。
- 「ペンギンスタチュウ」などで限界突破すると上限が上がります。最大RANKは200です（SUN PLUSで100から引き上げ）。
- RANK25・50・100で、それぞれ限界突破の証・真・限界突破の証・絆・限界突破の証のスキルシードが手に入ります。
- PARADISE LOSTまではキャラクターごとに固有のスキルがありました。NEWからはスキルシードの仕組みに変わり、キャラクターとスキルは別々になりました。
- Mateで、動くキャラクター「メイト」とメイトルームが追加されました。
