## 用語集

### ゲーム関連

- 大型アップデート：およそ半年に一回、冠するタイトル自体が変化するアップデート。基本的に、CHUNITHM 〇〇→CHUNITHM 〇〇 PLUSというふうに変化し、1年程度で冠するタイトルが丸々変わる。ただし、PARADISE→PARADISE LOST（PLUS相当）や、VERSE→X-VERSE→X-VERSE-Xのような例外的な変更もある。
- バージョン：大型アップデートで変わったタイトルを冠している期間に動作したCHUNITHM、もしくはタイトルそのもの。
- CHUNITHM-NET：CHUNITHM公式プレイヤーズサイト。プロフィールやスコアを確認できる。ここでブックマークレットを動かしてスコアデータを収集する。

### 楽曲・譜面関連

- 通常楽曲/譜面：WORLD'S ENDでない楽曲/譜面を指すバクロニム。
- 難昕度：通常譜面が持つ属性の一つ。簡単な順にBASIC(BAS)、ADVANCED(ADV)、EXPERT(EXP)、MASTER(MAS)、ULTIMA(ULT)がある。すべての通常楽曲はBASIC〜MASTERの4譜面を持ち、一部楽曲のみULTIMA譜面を追加で持つ。
- レベル：すべての通常譜面にある、1〜16の数値で指定された難しさをあらわす値。より以降には13+のようなプラスのついた中間レベルがある。
- 譜面定数：レベルよりも細かい内部レベル。0.1刻み。レーティングやOVER POWERの計算に関わる値。公式には表示されず、有志の検証によってOVER POWERやレーティングから逆算されるまではわからない。レベルと対応しており、例えば+なしなら.0〜.4、+ありなら.5〜.9となる。レベル10未満の場合細かい譜面定数は設定されず、9なら9.0、9+なら9.5と決定される。
- WORLD'S END：通常の譜面の框組から外れた特異な譜面が隔離された特殊難昕度。プレイヤーの実力計算に一切かかわらない。通常譜面と違い、★〜★★★★★の5段階のレベルと、漢字1文字or「！」「？」の譜面属性を持つ。
- ランプ：「ハードでクリアしたか」「フルコンボしているか」「フルチェインしているか」などを表すマーク。公式の用語でなく、BEMANIシリーズの同概念の借用。詳細は後述。
- 判定：ノーツをどれくらい正確に取ったかの指標。各ノーツにつきMISS（触れていない）、ATTACK（タイミングがずれている）、JUSTICE（ほぼ正確）、JUSTICE CRITICAL（正確）の4段階。配点はMISSが0%、ATTACKが50%、JUSTICEが100%、JUSTICE CRITICALが101%。JUSTICE CRITICALの上位概念としてJUSTICE HEAVENもあるといわれているが、こちらはスコアに関わらないほか詳細が不明。

### プレイヤー関連

- プレイヤー名：ゲーム上に表示される名前。全角で8文字まで。

### 実力値関連

- レーティング：実力を表す数値。ベスト架と新曲架の単曲レーティングの合計÷50から計算される。公式の表記では小数点以下2桁で切り捨てられる。SSS+（1009000点）で最高値になる。
- OVER POWER(OP)：実力を表す数値。すべての楽曲から計算される。理論値（1010000点）まで関わる。
- 単曲レーティング/OVER POWER：譜面定数とスコアから計算される、1譜面あたりの実力値。
- ベスト架：全譜面のうち、現バージョンよりも前に追加された譜面から、単曲レーティングが高い順最大30譜面選択される。レーティング計算に使用。
- 新曲架：全譜面のうち、現バージョンで追加された譜面から、単曲レーティングが高い順に最大20譜面選択される。バージョンの切り替わりのタイミングでベスト架側で計算されることになる。

### ランプ関連

- コンボランプ：FULL COMBO/FC（ミスなし）、ALL JUSTICE/AJ（全ノーツJUSTICE以上）、ALL JUSTICE CRITICAL/AJC（全ノーツJUSTICE CRITICAL）の3種。ただしAJCはAJの一種で、AJはFCの一種といえる。AJCは公式にはない概念だったが最近は意識され始めている。
- クリアランプ（ハードランプ）：CLEAR（ゲーム内でゲージが適切に溜まったか）、HARD（MISS以下20以上/JUSTICE以下300以上で強制終了するスキルで生存しているか）、BRAVE（JUSTICE以下150以上で強制終了するスキルで生存しているか）、ABSOLUTE（JUSTICE以下50）、CATASTROPHY（JUSTICE以下10）がある。プレイ済みかつCLEARがついていないものはFAILEDと見なせる。強制終了したりしない限りはだいたいプレイしたらCLEARがつくので、CLEARがついても上手いとは言いづらい。
- フルチェインランプ：2人以上でFULL COMBOを取ったかどうかを表す。フルチェインの相手に低い難昕度の人がいれば金のFULL CHAINランプが、全员同じか高い難昕度ならプラチナのFU CHAINランプがつく。
