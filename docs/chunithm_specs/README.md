## 用語集

| 用語 | 説明 |
|------|------|
| AJ | All Justice。全てのノーツがJustice判定以上である状態。スコアが1,010,000点でない場合もAJと呼ぶ。 |
| AJC | All Justice Critical。AJかつスコアが理論値の1,010,000点の状態。CHUNITHMで最高の完全状態。 |
| FC | Full Combo。ブレイクなしでクリアした状態。AJより宽い概念。 |
| OP | OVER POWERの略。スコア精度を数値化した指標。 |
| ベストフレーム | ベスト対象曲中から単曲レーティング上位30曲を選出する框。 |
| 新曲フレーム | 新曲中から単曲レーティング上位20曲を選出する框。 |
| 理論値 | スコア 1,010,000点のこと。AJC達成時にのみ出る。 |
| 譜面定数 | 各譜面に設定された難易度を表す数値。レーティング・OP計算の基礎となる。 |
| Level Star | WORLD'S END譜面の難易度を表す1〜5の星の数。 |

## クリアランプ

CHUNITHMでは、クリア時の状態を表すランプが複数存在します。

### 主なクリアランプの種類

| ランプ | 説明 |
|--------|----------|
| FAILED | クリア失敗 |
| CLEAR | 普通にクリア |
| HARD | 特定の条件を満たしたクリア（詳細は後述） |
| BRAVE | 低体力状態でクリアした状態 |
| ABSOLUTE | 特殊なクリア条件を満たした状態 |
| CATASTROPHY | 最高難易度での特殊クリア状態 |

> **注意**: HARD以降の詳細な定義は、公式ドキュメントや実際のプレイ感覚に基づいて追記中です。

## コンボランプとフルチェーン

### コンボランプ

| ランプ | 説明 |
|--------|----------|
| NONE | コンボランプなし |
| FC | Full Combo（ブレイクなし） |
| AJ | All Justice（AJC以外） |

### フルチェーン

- **FULL CHAIN**: フルチェーン達成
- **FULL CHAIN PLATINUM**: フルチェーンの上位形態。AJCと深い関連があるとされる。

## レーティングの框組み

CHUNITHMのレーティングは以下の2つの框で構成されます。

- **ベストフレーム**: ベスト対象曲から単曲レーティング上位**30曲**
- **新曲フレーム**: 新曲中から単曲レーティング上位**20曲**

合計**50曲**でプレイヤーレーティングが算出されます。
框が50曲未満でも除数は**50固定**であるため、プレイ曲数が少ないほどレーティングが低くなります。

---

## OVER POWER

OVER POWERはスコア精度を数値化した指標です。

- 各譜面ごとに単曲OPが計算される
- 同一楽曲内では、最も高いOPを出した譜面のみが「楽曲OP」として採用される
- 理論値（AJC）達成時に最大OPが得られる
- WORLD'S END楽曲と削除済み楽曲は計算対象外

---

## WORLD'S END

- 通常譜面とは別管理される専用譜面
- レーティング計算・OP計算から完全に除外される
- Level Star（星の数：1〜5）で難易度を表現
- 属性（attribute）を持つ

---

## 新曲フレームの判定

新曲フレームの対象となる楽曲は、以下の要件を満たすものです。

- 現行バージョンのリリース日以降に公開された楽曲
- 公開日が未設定の楽曲

`songs.is_new` フラグは使用しません。
